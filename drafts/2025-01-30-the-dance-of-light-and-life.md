This is the story on why I'm building a financial tracker of my own.

To begin, let's jump for a moment to July 2023, when I was travelling to Medellin, Colombia. While going there on the plane, I was taking advantage of every bit of time, so I was programming on Vissu.app mid-flight. At that time, I was working mainly on the sign up / reset password / log in flows. 

So, while on the plane, this lady next to me asked me what I was doing, and I was explaining to her, forgive the redundancy, that I was building a financial tracker app. It went a bit like this:

"Aren't there already many apps like that out there?", she asked.

"Yes, there are", I replied, while continuing to focus on whatever I was doing.

"Then, why are you building another one?", continued the lady.

"Because I didn't like the ones I've used so far, so I've decided to build my own", I explained.

## * * *

While I have always been good at keeping tabs mentally on almost virtually everything, there came a moment in my life when I was heavily invested in Bitcoin but I didn't know how much I had exactly invested.

This was a result of two things. First, using Bitcoin as a means of transfering money from Colombia to Venezuela without having to wait for hours. Using P2P marketplaces, I was able to get money into my family's hands pretty quickly. Secondly, the fact that I started to invest and buy Bitcoin as a long term investment.

Long story short, I didn't know exactly how much money I had put into my investments, so I set out to make a way to measure that.

How? Well, Excel... Or Apple Numbers, in this case. I ended up using a phone app, paired with 2 different spreadsheets.

I tried and tested almost all financial apps out there like Monefy, Lunch Money, Monarch, Wallet by budgetbakers, etc, but while I liked some stuff they did, I still didn't find all the functionalities that I'd need or expect in a financial app.

I settled for using Monefy on the phone for COP and USD tracking, with 2 spreadsheets to track my crypto holdings. I originally was using an app to track crypto holdings, Blockfolio, before it was acquired by FTX.

But I grew tired of having my financial data segregated across different places...

So I set out to the task of building my own. 

I dedcided to start building my own financial tracker! We named it Vissu, because Vissu come from Icelandic and it means "Certainty". I wanted to be certain of my finances. Thus, Vissu was born.

I had a background in OOP, as well as C, HTML, CSS from back in college. When I started this challenge, I chose React as the language to code in and Next.JS as the framework. 

While I initially used ChatGPT to build some really basic versions, that was the rush of the moment right when ChatGPT was rolling out massively and everyone was paying attention to it. During the spans of about two weeks, I built very simple apps which had very basic account fucionality, learning what was possible with LLMs at that moment.

I decided to take some time to study the documentation for both React and Next.JS, which took me about 2 months.

During this time, I tried hiring someone to help me build the app using LLMs, but that didn't go very welll, and after $1000 dollars spent, I reliazed that hiring someone so that they learned to program wasn't the best idea. 
 
Then, I decided to just do it all myself and started coding alongside ChatGPT, since LLMs were already pushing out newer versions, and I saw the potential.

Originally, it was just me using ChatGPT in my browser, then copying and pasting into Visual Studio Code. I had started using Copilot and it was pretty neat with Visual Studio Code. 

Eventually, I learned about Cursor via X, and specifically about using Cursor with the Copilot extension added, which I alraedy had, so I went for it!

It was the best coding decision that I've made in my entire coding career, aside from studying informatics back in the University.

## * * * 

When I started using Cursor, it was mostly ChatGPT back then, but soon thereafter updates started rolling in. I started to use Claude 3.5 Sonnet and it was truly a game changer. Originally, it was just me talking to Claude and making it do things, then I would go over and manually copy and paste.

As I learned more, it has been more usual that I do the changes and only use Claude whenever I don't know how to do something, or run into an error and need help fixing it.

It's funny that I have only recently started to "Apply" the code directly, instead of copying and pasteing myself. 

It's been almost two years now, and I continue to code Vissu.app during my free time. The first version should come out within the next 3 months.

AI continues to innovate and there's developments coming out almost weekly now, which is both amazing and terrifying, how do most people keep up?
